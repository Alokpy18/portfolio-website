# Alok Kumar Singh - Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Features
- Responsive design for mobile and desktop
- Animated star/space background
- Typing animation
- About, Skills, Projects, Resume and Contact sections
- Project cards with GitHub links
- Mobile navigation menu

## How to run
1. Open the folder in VS Code.
2. Open `index.html` in a browser.
3. For the best development experience, use the VS Code Live Server extension.

## Personalize
- Replace the email in `index.html`.
- Replace the LinkedIn URL with your LinkedIn profile.
- Put your resume PDF inside `resume/` and name it `Alok_Resume.pdf`.
- Add your project screenshots inside `images/` and connect them to the project cards if desired.

## Deploy
You can upload this folder to GitHub and deploy it using GitHub Pages or Netlify.
